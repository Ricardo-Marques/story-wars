# Round 1

Make the following improvements
1- Topics should be realistic, because we're talking about real stories. So things like "worst superpower ever" don't make sense. Stick to topics which make for good prompts for real stories.
2- When the player is done setting up their stories, show the names of the players we're still waiting for.
3- Skip the "start voting" prompt for the leader. When everyone is ready, the game should just start.
4- The author of the story should still be able to vote. Otherwie it's obvious who it is. It should just not count their vote.
5- Players should be able to change their answer in case of misclick. There should be a button to finalize the vote. Once everyone finalizes, it gives the answer.
6- Players should be able to refresh and continue in case of an issue.
7- Topics should be numbered, starting with topic 1. The topic should be read with TTS before the answer.
