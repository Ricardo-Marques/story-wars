# Prompt:

Make the following improvements

- List of improvements

Ask questions if you need to on how to achieve any of these requests.

# Round 1

1- Topics should be realistic, because we're talking about real stories. So things like "worst superpower ever" don't make sense. Stick to topics which make for good prompts for real stories.
2- When the player is done setting up their stories, show the names of the players we're still waiting for.
3- Skip the "start voting" prompt for the leader. When everyone is ready, the game should just start.
4- The author of the story should still be able to vote. Otherwie it's obvious who it is. It should just not count their vote.
5- Players should be able to change their answer in case of misclick. There should be a button to finalize the vote. Once everyone finalizes, it gives the answer.
6- Players should be able to refresh and continue in case of an issue.
7- Topics should be numbered, starting with topic 1. The topic should be read with TTS before the answer.

# Round 2

1- Give the leader a notification to let them know that the game room link has been copied to their clipboard
2- Show the name of the leader in the "Joining room" screen, instead of "Joining room <code>" it should be "Joining <player name's> room"
3- Increase voting time range. Should be between 10 seconds and 10mins. Make the default 1 min.
4- On the post answer screen, show how scores changes. For example you can show something like
Name +2 3->5
but make it nice

# Round 3

1- The countdown timer shows 379s and so on. Use mm:ss instead

# Round 4

1- Should have a minimum requirement of 3 players to start the game.
2- When a user joins by code, they have a "Copy invite link", but no "share invite link" like the leader. Both views should have the same buttons: copy link (copies to clipboard) and share link (current "share invite link" functionality, without the "invite" word)

# Round 5

1- "Play again" should return the leader to the setup screen, with the same players, rather than return to the home screen.
Players that are not the leader should see "Leader starting a new game" While staying on the results screen.
2- Non leaders should not have a "play again" option. Only the leader can start a new game. Non leaders can have an "exit game" option. Leaders should have this option too actually.

# Round 6
